# QUEMSI — Data management for Developers
Quemsi is a data management platform built for developers. You can get more info at [quemsi.com](https://quemsi.com)

## quemsi-model
This repository contains all class definition used as API contract between [quemsi.com](https://quemsi.com) and [quemsi agent](https://github.com/quemsi/quemsi-agent). These classes includes Api spesification for agent to use, DTO classes and flow model classes. You can understand all of communication and meta-data structure just by analyzing this repository.

### Technology Stack
- JDK 21
- Spring
- Hibernate
- Jackson
- Commons Compress

Moreover, you can find quemsi-commons source code [here](https://github.com/quemsi/quemsi-commons)
